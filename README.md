# Windows 11 Security Hardener

Профессиональный инструмент для системных администраторов для управления политиками безопасности Windows 11 через графический интерфейс.

## ⚠️ Важное предупреждение

Этот инструмент предназначен **только для использования системными администраторами** в легитимных целях управления корпоративной безопасностью. Неправильное использование может привести к нестабильности системы.

## 🚀 Возможности

### Вкладка "Система"
- Блокировка редактора реестра (regedit)
- Запрет командной строки (cmd)
- Отключение PowerShell
- Блокировка диспетчера задач
- Запрет панели управления
- Блокировка приложения "Параметры"
- Отключение сочетания клавиш Win+R

### Вкладка "Приложения"
- Черный список исполняемых файлов (.exe)
- Блокировка игровых платформ (Steam, Epic Games)
- Запрет запуска программ из временных папок (%TEMP%, %APPDATA%)

### Вкладка "USB и Сеть"
- Режим "Только чтение" для USB-накопителей
- Полное отключение USB-портов
- Сетевые ограничения

### Вкладка "Браузер"
- Запрет установки расширений
- Блокировка инструментов разработчика (F12)
- Запрет сохранения паролей в браузере

### Вкладка "Журнал"
- Просмотр логов в реальном времени
- Автоматическое сохранение в `C:\ProgramData\WinSecHardener\audit.log`

## 📋 Требования

- **ОС:** Windows 11
- **Права:** Учетная запись администратора
- **ПО:** Python 3.8+ (требуется только для сборки, не для работы готовой программы)

## 🛠️ Установка

1. Скачайте репозиторий:
   ```bash
   git clone https://github.com/ваш-пользователь/win-security-hardener.git
   cd win-security-hardener
   ```

2. Запустите установщик **от имени администратора**:
   - Нажмите правой кнопкой мыши на `install.bat`
   - Выберите **"Запуск от имени администратора"**

3. Дождитесь завершения установки:
   - Скрипт проверит права администратора
   - Установит необходимые зависимости (PyInstaller)
   - Скомпилирует программу в EXE-файл
   - Разместит программу в `C:\Program Files\WinSecHardener`
   - Настроит права доступа (ACL) — доступ только для администраторов
   - Создаст ярлык на рабочем столе

## ▶️ Использование

1. Запустите программу с ярлыка на рабочем столе или из меню Пуск
2. Подтвердите запрос UAC (контроль учетных записей)
3. Настройте необходимые политики безопасности в соответствующих вкладках
4. Нажмите **"Применить всё"** для активации настроек
5. Используйте кнопку **"Сбросить всё"** для возврата к настройкам по умолчанию

## 🔒 Безопасность

- Программа требует прав администратора для запуска
- Установочная папка защищена ACL (доступ только для группы Administrators)
- Все изменения логируются в файл аудита
- Нет скрытых паролей — используется стандартная модель безопасности Windows

## 🗑️ Удаление

Для удаления программы:
1. Запустите `C:\Program Files\WinSecHardener\uninstall.exe` (если создан)
2. Или вручную удалите папку `C:\Program Files\WinSecHardener`
3. Удалите ярлык с рабочего стола
4. Перезагрузите компьютер для полного сброса политик
